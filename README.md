# Exam Writing Logic

เก็บ "logic การเขียนตอบข้อสอบ" ของอาจารย์แต่ละท่าน สรุปด้วยคำของตัวเอง ใช้ทบทวน ฝึกเขียน และให้ AI ช่วยตรวจ

> ⚠️ แนะนำให้ตั้ง repo เป็น **Private** ถ้าใส่ไฟล์ต้นฉบับใน `sources/`

## โครงสร้าง
- `teachers/` สรุป logic ของอาจารย์แต่ละท่าน
- `templates/` โครงเปล่าให้กรอกตอนฝึกเขียน
- `examples/` ตัวอย่างคำตอบสั้นๆ ตาม logic
- `prompts/grader-prompt.md` prompt ให้ AI ตรวจคำตอบ
- `sources/` ไฟล์ต้นฉบับ (ไม่ถูก commit ตาม .gitignore)

## เปรียบเทียบเร็ว

| | CT | K | PK |
|---|---|---|---|
| คำถามที่อาจารย์ถามในใจ | จำได้ไหม | อธิบายได้ไหม | คิดครบไหม |
| คะแนนอยู่ที่ | ตัวบทเป๊ะ + form | เหตุผลตอนปรับข้อเท็จจริง | ครบองค์ประกอบ + ประเด็นแทรก |
| หลักกฎหมาย | ก้อนบนสุด ท่องเป๊ะ | แทรกสั้นๆ ในแต่ละประเด็น | ลิสต์มาตรา + อธิบายในวินิจฉัย |
| จัดตาม | ประเด็น | ประเด็น | บุคคล |
| สรุป | สั้น ตรงคำถาม | ต้องมีเหตุผลรองรับ | บูลเล็ตรวมท้ายข้อ |
| ความยาว | ไม่เกิน 2 หน้า (ควร 1.5) | ห้ามร่ายยาว | ยาวตามจำนวนผู้กระทำ |
