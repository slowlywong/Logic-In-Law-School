# อาจารย์ K

## หลักคิด
เน้นวินิจฉัย ไม่เน้นร่าย ทุกข้อสรุปต้องมีเหตุผลที่ปรับกับข้อเท็จจริง

## โครงสร้างคำตอบ
- คนแรก/ประเด็นแรก: **Issue → Law → Application → Conclusion**
- คนถัดไป: **Fact → Law → Application → Conclusion**
- คนที่หลักซ้ำกับที่เขียนแล้ว: **Application → Conclusion**

## ข้อควรทำ
- อ่านโจทย์ให้ดีว่าถามอะไร ตอบให้ครบทุกประเด็นที่ถาม
- แทรกหลักกฎหมายสั้นๆ ในแต่ละประเด็น แล้วปรับทันที
- ส่วนปรับข้อเท็จจริงต้องหนักที่สุด ใส่ "เพราะ..." ทุกข้อสรุป
- สรุปท้ายแต่ละประเด็น

## ข้อห้าม
- วินิจฉัยประเด็นที่โจทย์ไม่ถาม
- เขียนตัวบททั้งหมดก่อน / ร่ายประเด็นทั้งหมดก่อน
- ไม่อธิบายหลักกฎหมาย
- ปรับข้อเท็จจริงน้อย
- สรุปธงว่าผิดฐานอะไรโดยไม่อธิบายเหตุผล
- เขียนระวางโทษ

## เกณฑ์ให้คะแนน
จับประเด็นจากข้อเท็จจริง → ตอบครบ → อธิบายหลักถูก → ปรับใช้ได้ → เหตุผลสอดคล้อง

## เช็กตัวเองก่อนส่ง
- [ ] ตอบเฉพาะที่โจทย์ถามหรือยัง
- [ ] ทุกการวินิจฉัยมี "เพราะ" หรือยัง
- [ ] ส่วนปรับยาวกว่าส่วนหลักหรือยัง
- [ ] บอกองค์ประกอบของแต่ละมาตราได้ครบ
- [ ] อธิบายความต่างของมาตราที่คล้ายกันได้
- [ ] แต่ละมาตราใครรับผิด มีข้อแก้ตัวอะไร
- [ ] วิจารณ์ตัวบทได้ว่ามีข้อดีข้อเสียอย่างไร
- [ ] หากเป็นเรื่องค่าเสียหาย ต้องสามารถแยกค่าเสียหายเป็นรายการพร้อมมาตราได้
